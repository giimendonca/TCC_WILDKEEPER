## Requisitos Não Funcionais (RNF)

RNF01 O sistema deverá ser desenvolvido utilizando HTML5, CSS3, JavaScript, PHP e MySQL.

RNF02 O sistema deverá possuir interface responsiva.

RNF03 O sistema deverá funcionar nos navegadores Google Chrome, Microsoft Edge e Mozilla Firefox.

RNF04 O sistema deverá possuir autenticação de usuários.

RNF05 As senhas deverão ser armazenadas de forma criptografada.

RNF06 O sistema deverá validar os dados inseridos nos formulários.

RNF07 O banco de dados deverá manter a integridade referencial entre as tabelas.

RNF08 O sistema deverá apresentar mensagens de sucesso e erro para todas as operações.

RNF09 O tempo médio de resposta das operações deverá ser inferior a três segundos em ambiente local.

RNF10 O código deverá seguir padrões de organização e boas práticas de programação.
